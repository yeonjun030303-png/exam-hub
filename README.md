# 학습 카드 허브 (응급구조사 2급 / HSK4급 / 컴활 2급)

## 폴더 구성
- hub.html            : 첫 화면(허브)
- emt2_quiz.html       : 응급구조사 2급 필기 카드+모의고사
- hsk4_quiz.html       : HSK 4급 카드+모의고사
- comp2_quiz.html      : 컴활 2급 필기 카드+모의고사
- exam-core.js         : 목표량/모의고사/등급/AI진단 공용 엔진
- storage-shim.js      : GitHub Pages 등 외부 호스팅에서도 저장 기능이 동작하게 해주는 파일

6개 파일은 반드시 같은 폴더에 함께 있어야 정상 동작해요.
모든 데이터(프로필/목표량/오답노트/모의고사 기록)는 서버가 아니라 접속한 사람의 브라우저에만 저장돼요.
(말벗처럼 전화번호로 로그인해서 여러 기기에서 같은 기록을 보는 기능은 없어요 — 그러려면 별도 서버가 필요해요.)
